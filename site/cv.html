PvAPI Go, Gin, pgx, PostgreSQL

Backend for a consignment marketplace, rewritten from Laravel to Go (489 commits, Mar–Jun 2026). Checkout runs in one transaction with row-level locks on the client, package and shop rows; money uses decimal and per-shop values are frozen at write time. Checkout idempotency went through three documented designs, from a client-supplied key to a content hash to a per-client rate limit after a production incident. Partner API with SHA-256-hashed tokens, per-entity authorization gates, 53 migrations and 19 black-box HTTP test suites against a real PostgreSQL. From May 2026 I ran it with coding agents: 64 written specs, guardrails in AGENTS.md, and custom skills for tests and diagrams.
